# Treffpunkt

Eget nettprosjekt. Ikke en endring i den originale Flutter-appen.

Dagboken har NSF-programmene (luftpistol og fin/grov) med helringscoring, og IPSC som egen kategori: treff på skive, tid og hit factor.

Økter lagres lokalt i nettleseren. Synk krever prosjekt-URL og nøkkel, og er ikke skrudd på.
